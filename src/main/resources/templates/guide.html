用户指南

认识四个分区

站里的内容分四类，在「我的笔记」里用顶上那排切换：

  • 闪念：随手记的想法、学习记录、踩坑总结
  • 项目：自己做过的东西
  • 八股：面试题和答案，按技术分类归档
  • 算法：题解和思路

左边那棵树是目录，点分组标题就能收起或展开。

新建与编辑

  • 新建：左边目录顶上那个「+」加到最外层，某一行末尾的「+」加到那一项下面——填个名字回车就好，不用填别的
  • 改正文：正文页上点「编辑」，正文原地变成可以改的文字，改完「保存」就生效，不跳页面
  • 标题、可见性、上级目录这些在左树那一行的「⋯」里点「编辑」
  • 某一行的「⋯」里还有：重命名、复制链接、删除（连它下面的条目一起进回收站，30 天内能恢复）
  • 「当目录用」：编辑页里勾上就只做分类，列表里不占卡片，可以在它下面继续新建
  • 正文用 Markdown 写，右边实时预览；要插图就点「插入图片」
  • 「补充笔记」在编辑页下面直接写一段（或者把 AI 整理好的贴进来），保存后正文末尾会生成一张卡片，点开就是这一篇

可见性怎么选

每条内容都要挑一个可见性：

  • 公开：谁都能看，也会出现在技术广场
  • 会员可见：没登录只能看到标题，登录后才读得到正文
  • 私密：只有你自己能看

想让朋友看某一篇又不想公开，就选「会员可见」，把链接发给他——他登录之后能读全文。

星级与标签

八股题后面有星级（1 到 3 星），拿来记这题的重要程度。

  • 点星星改星级，再点同一颗清回 0 星
  • 顶上「★★★」「★★以上」「未评」按档筛，带「以上」的是这一档及以上
  • 「收藏」是另一套：正文页标题下点「☆ 收藏」就进了收藏夹
  • 卡片下面的标签是读题时自动打的，顶上那排点一下就按它筛，还能和星级叠着用

评论与注释

选中正文里的一段文字，会浮出工具条：

  • 评论：写进右栏，对这一段有疑问、有一点小见解就写这儿
  • 注释：长解释、贴代码都写这里，正文里留一条短虚下划线，点开看
  • 高亮：挑个颜色给这段铺底纹。别人在线看这一篇时看不到你标的高亮，但把这一篇复制到自己空间时会跟着一起带过去

标题下面的「加书签」能标记这一块，下次从书签点一下就能回到这里。

技术广场

广场上摆的都是公开内容，按分类排：八股的各分类、算法、项目。点分类能看条目清单。

登录后点「加入我的空间」，会把这一组连星级、标签、高亮一起复制一份到自己名下，之后随你改，原版更新不影响副本。

把内容发给朋友

没放进广场的内容，把链接直接发给朋友：公开和会员可见的链接，对方打开就能看 （会员可见的要先登录）。私密的只有你自己能看，链接发出去别人也打不开。

用 AI 存笔记

  1. 登录后点右上角头像进「我的」
  2. 「AI 接入」里点「生成 Token」
  3. 点「复制给 AI」，把这一整段粘给 Claude Code / Cursor / Claude Desktop，它按里面的步骤配好
  4. 之后直接跟它说「帮我整理一下刚才的讨论，生成一篇笔记存到我账号里」

目录也能让它建：说「给我开一个 Python 的分类，顺手把这几篇放进去」就行， 新建分类和建笔记都是同一套动作。

存之前它会先查重，再问你这篇给谁看。Token 只显示一次，丢了点「重新生成」。

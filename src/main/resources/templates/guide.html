我的笔记

四类内容放在一起，顶上那排切换：

  • 闪念：随手记的想法、学习记录、踩坑总结
  • 项目：自己做过的东西
  • 八股：面试题和答案，按技术分类归档
  • 算法：题解和思路

四类的地址分别是 /notes、/projects、/bagu、/algo， 收藏过的链接不会变。左边那棵树是目录，点分组标题收起 / 展开，收起状态记在这台浏览器里。

星级与标签

八股题后面有星级（1 到 3 星），用来记这题的重要程度。

  • 点星星改星级，再点同一颗清回 0 星
  • 顶上「★★★」「★★以上」「未评」按档筛，带「以上」的是这一档及以上
  • 「收藏」是另一套：文章页点「☆ 收藏」收进收藏夹（/memo）
  • 卡片下面的标签是读题时自动打的，顶上那排点一下就按它筛，能和星级叠着用

阅读页

左边的树跟着这篇内容所属的目录走，右边正文里的 ## 小标题会变成右侧目录。 选中正文里的一段文字会浮出工具条，三个去处：

  • 评论：写进右栏，对这一段有疑问、有一点小见解就写这儿
  • 注释：长解释、贴代码都写这里，正文里留一条短虚下划线，点开看
  • 高亮：挑个颜色给这段铺底纹，只有自己看得到

标题下面还有星级、「☆ 收藏」、「加书签」；书签在 /bookmarks 里能跳回具体位置。 同一条内容下次打开会接着上次读到的位置。

技术广场

广场上只摆公开内容，按分类排：八股的各分类、算法、项目。点分类进去看条目清单； 登录后点「加入我的空间」会把这一组复制一份到自己账号下，之后随你改，原版更新不影响副本。

会员可见和私密的内容不在这儿——那两种只有作者把链接发给你才看得到。

用 AI 存笔记

  1. 登录后点右上角头像进「我的」
  2. 「AI 接入」里点「生成 Token」
  3. 点「复制给 AI」，把这一整段粘给 Claude Code / Cursor / Claude Desktop，它按里面的步骤把 MCP 配好
  4. 之后直接跟它说「帮我整理一下刚才的讨论，生成一篇笔记存到我账号里」

存之前它会先查重，再问你这篇给谁看（公开 / 会员可见 / 私密）。Token 只显示一次，丢了点「重新生成」。
